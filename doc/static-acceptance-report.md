## 5 证据与限制

- 本报告全部证据为**文档条款与编号**，不含审计事件 ID、发布记录 ID、读回 MD5、TraceId 或运行截图，因此不能作为运行时验收证据。
- **PASS 的边界**：仅表示对应条款在文档层面自洽、编号可追踪、约束可落到实现粒度，**不代表运行时通过**。
- **运行时验收**：须按 spec 附录 C.2 模板另出报告，按附录 C.3 判定；每条 P0 场景的证据至少包含“审计事件 ID、发布记录 ID、读回 MD5、TraceId、截图”中的两项。
- **BLOCKED 的边界**：表示数值或文档交付缺口导致无法完成 P0 验收，不等同于 FAIL；闭环前不得签署 P0 运行时验收结论。
